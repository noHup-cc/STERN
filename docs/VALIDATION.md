## Terms

This package was validated against the analysis of the paper before release, in two environments:
the paper environment (`environment-paper.yml`, the library versions of the paper) and a modern one
(`environment.yml`). Terms of this report:

- **stage 02 / JPEG files**: the slice images of the paper (one JPEG per z slice and time point). *JPEG
  bytes from the raw data* re-renders them from the raw volumes with `stern.preprocess` and compares bytes.
- **stage 03 features**: the slice features of the paper's analysis, released in the data record
  (`features_<dataset>.zip`). *From files*: this package's network applied to the paper's JPEG files;
  *from raw*: applied to slices rendered from the raw volumes. Three time points per dataset (first,
  middle, last) from files, the middle one from raw.
- **archived algorithm**: the original analysis code of the paper (volume distance and z ranges of the
  mouse embryos), executed unchanged, compared with `stern.distance` / `stern.zranges` on the same features.
- **stage 04**: the paper's results (heart distance matrices, zebrafish cross-view matching) recomputed
  from the same features with the original code. *Original values*: the result tables of the paper as
  computed on the original machine (for information).
- **self-distances**: distances of a volume to itself (query time = target time), zero up to rounding.
- **strict pass** (paper environment): JPEG bytes and features bit-identical, every distance within
  tolerance, best matches and Spearman rho equal to the published ones. **modern pass** (modern
  environment): the same matching results, distances within tolerance except the self-distances.
- **datasets**: `mouse_A`-`mouse_D` (mouse embryos A-D), `heart_A`-`heart_C` (mouse hearts A-C), `zf_G1` and
  `zf_G2` (zebrafish views 1 and 2 of the paper).
- **code version**: the validation ran the code of this release before its final edits, which changed only docstrings, comments and description texts, not the program code.
